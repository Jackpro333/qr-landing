## 1. 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 프론트엔드 전체. 홈, 관리자(`?admin`), 물건 페이지(`?t=코드`) |
| `supabase.sql` | 백엔드 전체. 표, 보안 규칙, 업로드 허가, 저장소(Storage) 설정, 서버 함수 |
| `설치가이드.md` | 이 문서 |

## 2. 이미 운영 중인 사이트에 업데이트 적용하기 (memtag 프로젝트)

순서가 중요해요. **SQL을 먼저 실행하고, 그다음 index.html을 올리세요.** 순서를 바꾸면 그 사이 몇 분 동안 글쓰기가 실패해요.

1. https://supabase.com/dashboard 에서 `memtag` 프로젝트 → 왼쪽 **SQL Editor** → **New query**
2. `supabase.sql` 내용을 전부 붙여 넣고 **Run**. `Success. No rows returned`가 나오면 끝이에요.
   - 기존 태그와 기록은 그대로 남아요. 이 SQL은 여러 번 실행해도 안전하게 짜여 있어요.
   - 이때 사진·영상 저장소 `memtag-media`도 자동으로 만들어져요(공개 읽기, 파일당 50MB, 사진·영상 형식만 허용).
3. https://github.com/Jackpro333/qr-landing → **Add file → Upload files** → 새 `index.html`을 끌어다 놓고 **Commit changes**
4. 1~2분 뒤 https://jackpro333.github.io/qr-landing/ 를 새로고침하면 새 홈페이지가 보여요. 예전 화면이 보이면 브라우저 캐시 때문이니 한 번 더 새로고침하세요.

## 3. 처음부터 새로 설치할 때

1. https://supabase.com 에서 무료 프로젝트를 만들어요(Region은 가까운 아시아 지역).
2. SQL Editor에서 `supabase.sql`을 실행해요.
3. **Authentication → Users → Add user**로 관리자 계정을 만들고(Auto Confirm 체크), SQL Editor에서 아래를 실행해요.
   ```sql
   insert into public.admins (email) values ('관리자이메일@example.com');
   ```
4. **Authentication → Sign In / Providers**에서 **Allow new users to sign up**을 꺼요.
5. **Project Settings → API Keys**에서 Project URL과 `anon` `public` 키를 복사해 `index.html` 위쪽 `CONFIG`에 넣어요. `service_role` 키는 절대 넣지 마세요.
6. `SITE_URL`에 사이트 주소를 넣고 GitHub Pages에 올려요. QR에 인쇄되는 주소라 나중에 바꾸지 않는 게 좋아요.

## 4. 사용하는 방법

### 관리자 (`?admin`)
- 개수와 묶음 이름을 정하고 **QR 생성하기**를 누르면 QR과 각각의 물건 페이지가 함께 생겨요.
- 카드마다 **페이지 열기 / PNG 저장 / 주소 복사 / 삭제**가 있어요. 삭제는 두 번 눌러야 지워져요.
- 필터와 검색으로 고른 뒤 **보이는 QR 인쇄**를 누르면 A4에 3열로 인쇄돼요.

### 처음 찍은 사람
- 물건 이름, 한 줄 설명, 이름, 함께한 시기, 첫 사연, 페이지 분위기(기본/크리스마스)를 적으면 **초대 주인**이 돼요.
- 등록 직후 나오는 **주인 열쇠**를 꼭 메모해 두세요. 폰을 바꾸면 이 열쇠로 다시 주인임을 증명해요.

### 주인: 새 이야기 남기기
페이지의 **새 이야기 남기기**에서 종류를 골라요.

| 종류 | 적는 것 | 첨부 |
|---|---|---|
| 사연 | 그날 있었던 일 | 사진·영상 |
| 노래 | 유튜브 링크, 노래 제목(링크를 붙이면 자동으로 채워짐), 고른 이유 | 유튜브 영상 |
| 수리·정비 | 어디서, 무엇을, 얼마에 고쳤는지 | 사진·영상 |
| 메모 | 보관법, 버릇, 다음 주인에게 하는 부탁 | 사진·영상 |

- 유튜브 링크는 유튜브 앱의 **공유 → 링크 복사**로 받은 주소면 다 돼요. `youtu.be/…`, `youtube.com/watch?v=…`, 쇼츠, 유튜브 뮤직 링크를 모두 알아봐요.
- 사진·영상은 **사진·동영상 추가**를 누르거나 끌어다 놓으면 미리보기가 나와요. 미리보기의 ×로 뺄 수 있어요.
- 아이폰 동영상(MOV)은 아이폰·맥에서는 잘 재생되지만, 일부 안드로이드·윈도우 브라우저에서는 재생이 안 될 수 있어요. 모두에게 보여야 하는 영상이면 MP4로 올리는 게 안전해요.

### 넘길 때: 양도
1. 지금 주인: **양도하기 → 양도 코드 만들기** → 8자리 코드를 새 주인에게 알려 줘요(7일 유효).
2. 새 주인: 태그를 찍고 코드, 이름, 첫 이야기를 넣으면 소유권을 받아요.
3. 이전 주인의 이름은 지워지고, 그 사람이 남긴 사연·노래·사진은 그대로 남아요.

## 5. 보안은 이렇게 지켜요

- **읽기는 누구나**, **쓰기는 주인 열쇠가 있는 사람만** 할 수 있어요. 열쇠는 서버에 암호화(해시)된 값으로만 저장돼요.
- 사진·영상 업로드는 주인이 서버에서 **업로드 허가증**을 받아야만 할 수 있어요. 허가증은 30분 동안 유효하고, 한 태그당 한 시간에 40개까지만 발급돼요. 그래서 아무나 저장소에 파일을 올릴 수 없어요.
- 기록에 붙는 파일은 서버가 "이 태그용으로 허가했고 실제로 올라간 파일인지" 다시 확인해요.
- 태그를 만들고 지우는 일은 `admins`에 등록된 관리자만 할 수 있어요.

## 6. 자주 묻는 질문

**Q. 저장 공간은 얼마나 되나요?**
Supabase 무료 요금제는 파일 저장소 1GB, 데이터베이스 500MB예요. 사진은 자동으로 줄여서 한 장에 보통 300~600KB라, 사진 위주라면 2천 장 정도 들어가요. 영상이 많아지면 유료 요금제(Pro)를 고려하세요.

**Q. 기록을 지웠는데 사진 파일은요?**
기록은 지워지지만 파일은 저장소에 남아요. 정리가 필요하면 Supabase **Storage → memtag-media**에서 태그 코드 폴더를 열어 지우면 돼요.

**Q. 부적절한 글이나 사진이 올라왔어요.**
글은 **Table Editor → entries**에서, 파일은 **Storage → memtag-media**에서 지우면 돼요.

**Q. 주인 열쇠를 잃어버렸어요.**
SQL Editor에서 아래를 실행하면 그 태그가 주인 없는 상태로 돌아가 다시 등록할 수 있어요. 기록은 남아요.
```sql
update public.tags set owner_count = 0, owner_name = '', transfer_pending = false where id = '태그코드';
```

**Q. 무료 프로젝트가 멈췄어요.**
일주일 동안 아무도 접속하지 않으면 일시 정지돼요. Supabase 대시보드에서 **Restore**를 누르면 다시 켜져요.

**Q. 체험해 보고 싶은데 실제 데이터에 섞이기 싫어요.**
주소 끝에 `?demo`를 붙이면(예: `…/qr-landing/?admin&demo`) 그 브라우저 안에서만 저장되는 체험 모드로 열려요. 체험 모드에서는 사진은 되고 동영상은 저장되지 않아요.
